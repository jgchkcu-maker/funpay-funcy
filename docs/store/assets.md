# Ресурсы 0.9.11

* Бывший дефолтный фон i.ibb.co заменён локальным CSS-градиентом. Только точное старое значение мигрирует; собственные фоны сохраняются.
* Встроенные обои «Туманный лес» (`themes/wallpapers/fog-pines.webp`) созданы для этого проекта инструментом OpenAI imagegen по запросу пользователя; файл включён в расширение.
* Звуки VK, Telegram, iPhone, Discord и WhatsApp исключены из исходного runtime и ZIP. Их id мигрируют в default; пользовательский звук сохраняется.
* Каталог funcy-assets и прежние ISO Republic presets не содержали достаточного подтверждения происхождения и условий для каждой картинки. В 0.9.10 список локально одобренных обоев пуст. JSON-каталог можно прочитать, но его записи не становятся доступными и не могут сами добавить себя в одобренный список. Запрос обоев напрямую тоже блокируется. Для возвращения нужны исходная страница, автор, лицензия/разрешение и закреплённая локальная запись ресурса.
* Текущие иконки Funcy и стартовый маскот сохранены из пользовательского checkout. Визуально это буква F и нейтральный робот; формальное подтверждение происхождения/прав должен сохранить владелец проекта до подачи. Автоматическая проверка прав на пользовательские исходники не заявляется.
* jQuery 3.7.1 и Material Symbols имеют notices и полные тексты лицензий в поставке. Исходная MIT-атрибуция AlliSighs сохранена.

Удалённый репозиторий ресурсов не изменён. Сохранённые пользовательские обои не удаляются из настроек; пользователь отвечает за свои загружаемые материалы.
