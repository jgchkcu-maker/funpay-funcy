# Снимки для карточки

Готовые изображения 1280×800 для кабинета лежат в `docs/store/screenshots/`:

1. `01-analytics.png`: обзор финансов (выручка, прибыль, потенциал склада).
2. `02-auto-delivery.png`: автовыдача со складом и шаблоном, предпросмотр сообщения покупателю.
3. `03-bulk-editor.png`: массовое редактирование выбранной категории.
4. `04-auto-reply.png`: автоответчик, тёмная тема меню.
5. `05-themes.png`: редактор своей темы с предпросмотром FunPay.

Все данные демонстрационные: выдуманные товары, покупатели и суммы, без названий реальных игр. Каталог тем на снимках пуст, пока не подтверждены права на его обои (`assets.md`).

## Готовый комплект для кабинета

Актуальный вариант по уточнению пользователя: `docs/store/upload-imagegen/` и архив `docs/store/funcy-store-assets-imagegen-0.9.12.zip`. Оба промо целиком сгенерированы через ImageGen, включая надписи, логотип и объёмные значки. После генерации выполнены только изменение размера и экспорт RGB PNG. Источники, промпты и метаданные: `docs/store/promo/imagegen/`. Ниже описан предыдущий вариант с отдельной композицией элементов, сохранённый для истории.

В `docs/store/upload/` собраны иконка, пять снимков, промо 440×280 и 1400×560, чистый текст описания и памятка по полям. Архив: `docs/store/funcy-store-assets-0.9.12.zip`.

Фон промо сгенерирован встроенным ImageGen. Логотип, русский текст и кадр настоящего интерфейса с демонстрационными данными добавлены при точном экспорте через Chrome; промо сохранены как RGB PNG без прозрачности. Источник фона, промпт и метаданные экспорта находятся в `docs/store/promo/`. Пересобрать промо и папку загрузки: `node tools/store-promo.cjs` с настроенным `FPT_PLAYWRIGHT`.

## Как переснять

```bash
node tools/store-screenshots.cjs
node tools/store-screenshots-frame.cjs
```

Первый скрипт запускает настоящие контентные скрипты расширения на демо-странице funpay.com с подменённым `chrome.*` и сохраняет кадры окна в 2x в `screenshots/raw/`. Второй собирает из них карточки 1280×800 с заголовками. Тексты заголовков задаются в `SLIDES` второго скрипта, экраны и демо-данные — в `SHOTS` и `demoData()` первого.

Нужны Chrome (`FPT_CHROME`, по умолчанию `C:/Program Files/Google/Chrome/Application/chrome.exe`) и Playwright (`FPT_PLAYWRIGHT`). Набор экранов можно сузить: `FPT_SHOT=theme,bulk`.
