# Снимки для карточки

Сделать на установленном staged пакете, скрыв имена, суммы, сессии, товар и переписку реальных покупателей. Старые README-снимки не подтверждают вид 0.9.11.

1. Главное меню Funcy на FunPay, нейтральный фон, без личных данных.
2. Автовыдача: настройки лота, переменные и пауза в шаблоне с демонстрационным товаром.
3. Журнал заказов: состояния ожидания и неопределённой отправки, товар замаскирован.
4. Автоответы / быстрые ответы с демонстрационными шаблонами.
5. Аналитика на демонстрационных данных.
6. Оформление с CSS-градиентом, своим фоном и стандартным звуком; без исключённых ресурсов.

Размеры и форматы сверить с текущими полями кабинета Chrome Web Store перед загрузкой. Снимки в этой задаче не подготовлены для публикации.
