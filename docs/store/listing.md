# Карточка Funcy 0.9.11

Название: **Funcy**.

Краткое описание: **Неофициальное расширение для FunPay: автоответы, выдача, заказы, аналитика и управление лотами.**

## Основное описание

Funcy добавляет в FunPay инструменты продавца: управление лотами и шаблонами, ответы покупателям, выдачу в чате, журнал заказов, аналитику продаж и настройку оформления.

Автоматические функции работают, пока запущен Chrome и действителен вход в FunPay. Вкладку сайта можно закрыть. События открытой страницы ускоряют обработку; фоновая проверка выполняется примерно каждые 30 секунд. Браузер может задерживать выполнение, а спящий компьютер не обрабатывает задания.

Каждая попытка выдачи сохраняется в локальном журнале. При потере ответа сообщение может быть доставлено: такие части не отправляются снова автоматически и требуют решения продавца. Длинные паузы шаблона сохраняются между запусками worker. `{quantity}` подставляет проверенное количество; инструкция отправляется один раз на заказ.

В 0.9.11 входящие сообщения читаются по ID и автору; история дочитывается при пропуске окна. Товар отправляется без добавленного служебного символа. Неизвестный автор, неподтверждённая история или прерванная обработка останавливают автоматический повтор; состояние видно в разделе автоответов. Первый проход после обновления устанавливает исходную границу без ответов на старую переписку. Пригодность конкретного товара нужно проверить продавцу.

Ползунок прокрутки меню сохраняет нейтральный серый цвет при смене темы сайта. Цвет прокрутки самой страницы по-прежнему настраивается.

Доступны собственный фон, цвета, стандартный звук FunPay и пользовательский отрывок звука. Каталожные обои без подтверждённых прав скрыты. При переводе полей выбранный текст передаётся Google Translate. AI, RMTHub и сторонние описания профиля недоступны.

Funcy не является официальным продуктом FunPay. Минимальная версия Chrome — 120.

## Перед подачей

* Опубликовать `privacy-policy.md` и вставить действующий URL в кабинет; не использовать вымышленную ссылку.
* Выбрать категорию из реально доступных в текущем кабинете разработчика.
* Сверить сведения о данных и разрешениях с `permissions.md` и политикой.
* Сделать актуальные снимки по `screenshots.md` после ручной проверки пакета.
* Проверить брендовые материалы и права по `assets.md`.
* Пройти `manual-acceptance.md`; публикация пакета не выполнена этой задачей.
