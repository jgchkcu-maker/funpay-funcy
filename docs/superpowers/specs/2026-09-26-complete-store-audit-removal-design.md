# Полное удаление ИИ-аудита магазина

Дата: 2026-09-26

Статус: спецификация утверждена; реализация не начата.

## Цель

Удалить функцию ИИ-аудита магазина из расширения FunPay Funcy и из актуальных проектных материалов. После изменения пользователь не должен видеть страницу, пункт меню, результаты поиска, элементы оформления или описание этой функции. В коде не должны оставаться её загрузчик, запросы и специальные режимы ИИ.

## Объём

### Код расширения

- Удалить `content/features/ai_lot_audit.js` и исключить её из `manifest.json`.
- Удалить разметку страницы и пункт меню из `content/ui/main_popup.js`, а также страницу из списка навигации, её заголовок и поисковый псевдоним.
- Удалить стили только для страницы аудита из `css/content_styles.css`.
- Удалить специальные типы `lot_audit_raw` и `lot_audit` из `background/ai.js`.
- Удалить описание функции из `README.md`.
- Удалить тест-контракт самой функции и убрать её из фикстур/ожиданий навигационных тестов. Новые тесты не добавлять.

### Документы и материалы

- Удалить ссылки и описания функции из датированных спецификаций, планов и навигационной QA-документации; соответствующие списки страниц и количественные итоги привести в соответствие.
- В пакете `funpay_funcy_ui_audit_spec_v4` удалить кадр F04, его упоминания и отдельный скриншот; перенумеровать последующие кадры и обновить общий итог с 51 до 50.
- Удалить каталог `текущее состояние/1. Лоты и продажи/4. Аудит магазина` с изображением страницы.
- Сохранить остальные разделы и материалы, не относящиеся к странице аудита.

## Совместимость сохранённого маршрута

В `openPopupPage` уже есть переход на `lot_io`, когда запрошенная страница отсутствует. Поэтому ранее сохранённое значение `fpToolsLastPage=ai_audit` безопасно откроет «Управление лотами» после обновления. Добавлять постоянную миграцию ради удаления ключа cooldown не требуется: после исключения модуля этот ключ больше не читается.

## Проверка результата

- Поиск по исходникам и текущим документам не находит идентификаторы, запросы или описания удалённой функции.
- Наборы страниц в навигации и тестовых фикстурах совпадают; страницы и её отдельного скриншота нет.
- Дифф проверен на случайные изменения в уже модифицированных файлах пользователя.
- Существующие тесты не запускать без отдельного запроса.

## Границы

Общие функции ИИ и прочие функции работы с лотами остаются без изменений. Общие отчёты аудита интерфейса сохраняются после удаления только относящегося к этой странице материала.
