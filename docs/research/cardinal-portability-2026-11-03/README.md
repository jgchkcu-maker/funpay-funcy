# Плагины FunPay Cardinal: что переносится в Funcy

Исследование на **2026-11-03** для **Funcy 0.9.13**. Результат — каталог и доказательная оценка, без внедрения функций и без восстановления удалённых интеграций.

Проверены деревья **353 обнаруженных репозиториев**; получены Python-исходники из 114 репозиториев, статически разобраны 525 уникальных Python-файлов. Просмотрена доступная публичная история **16 Telegram-каналов / 803 поста**, прочитаны статьи и 82 карточки товаров. Это охват обнаруженных публичных источников, а не всех существующих репозиториев и закрытых каналов.

## Результат по читаемым реализациям

| Вердикт | Семейств с кодом |
|---|---:|
| Полный перенос по архитектуре | 76 |
| Перенос с конкретными потерями | 4 |
| Для полноты нужен помощник/сервер | 7 |
| Недостаточно данных для полного вердикта | 43 |
| **Всего** | **130** |

Полный перенос означает сохранение существенного поведения в согласованном режиме: браузер работает, вкладка FunPay может быть закрыта, отдельного своего сервера/помощника нет. **Это не 76 уже реализованных или проверенных на живом аккаунте портов.** Вердикты относятся к выбранным версиям; другие варианты сохранены отдельно и не наследуют оценку автоматически. Дополнительно каталог содержит неподтверждённые Telegram-вложения, объявления и смежные инструменты: всего 331 карточка. Эти дополнительные записи не выдаются за доказанно уникальные рабочие плагины.

## Что действительно полезно переносить

1. **Контроль чатов без ответа** — ChatGuard / UnansweredReminder.
2. **Наблюдение за лотами и конкурентами** — VOLT Watch / CompetitorWatch, затем PriceDumper через общий writer.
3. **Товарные пулы** — ProductDoctor, StockMonitor, затем общий резерв и синхронизация ADSync / StockSync / Sales Manager.
4. **Алерты и сводки** — BalanceGuard, DailyDigest, SalesFunnel, RegularsDetector.
5. **Недостающие режимы общения** — NightMode, напоминание подтвердить заказ и AI-консультант с BYOK.

Графики, основные финансы, экспорт, массовые операции, клонирование, обычные автоответы, приветствия, ответы/бонусы за отзыв, аккаунты и расписания уже есть в Funcy. Их повторная реализация даёт меньше пользы, чем перенос конкретного недостающего сценария.

## Основные границы

- Нативный IMAP/POP3/SMTP, Minecraft TCP, произвольный Python/ОС и запуск sg.exe не становятся доступными от переписывания кода на JS.
- Python-библиотека, Selenium или Pyrogram сами по себе не доказывают необходимость помощника. HTTP, криптография и MTProto по WSS имеют браузерный путь; полнота конкретного сценария проверяется отдельно.
- Самостоятельные функции Telegram — мост чатов и удалённые уведомления — не выброшены из сравнения. Они возможны через Bot API при работающем браузере; 24/7 при выключенном ПК не обещается.
- Изолированный MV3-тест подтвердил HTTP с host permission, HMAC/Steam-алфавит, DNR User-Agent, Cookie jar и чтение checkpoint новым экземпляром worker. Это проверка среды, не реальных покупок/выдач.
- NS.Gifts /docs сейчас 410, SMMWay /api 404; проверяемая новая DesslyHub HMAC v2 спецификация недоступна. Не переносить на эти режимы доказательства из legacy v1.
- «Money Generator» в просмотренном коде — эффект на аватаре; «авто-отзывы покупателям» нельзя подтверждать одним вызовом send_review, который также обслуживает ответ продавца.
