# Правила проекта

## Выпадающие списки (`<select>`) — только кастомные

Нативный список браузера нигде не должен показываться. Любой `<select>` обязан открываться
тематическим меню проекта:

- **Внутри popup расширения (`.fp-tools-popup`)** — список подключается автоматически:
  `FPTPopupUI.observePopupControls` (`content/ui/popup_components.js`) вызывает `autoEnhanceSelect`
  для каждого добавленного `<select>`. Достаточно создать обычный `<select>` с `<option>` и вставить
  его в DOM. Вручную `enhanceSelect` нужно звать только если нужен свой контейнер-хост.
- **На страницах и окнах FunPay (вне popup)** — `content/features/page_selects.js` подменяет
  нативный список на тематическое меню в shadow root.
- Не использовать `<datalist>`, `size > 1`/`multiple` как замену выпадающему списку.
- Опт-аут допустим только осознанно: атрибут `data-fpt-native-select` (popup) или класс
  `fpt-page-select-off` (страницы). Новые исключения объяснять комментарием.
- Новые контейнеры, куда рендерятся `<select>` вне popup и вне `page_selects.js`, должны
  вызывать `FPTPopupUI.enhanceSelect(select, host)` явно.
- Выбор значения должен диспатчить `change` на оригинальном `<select>` — не читать значение из
  кастомного меню.
